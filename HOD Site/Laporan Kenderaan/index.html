Cara pasang (sekali sahaja)

  1. Buka Google Sheet laporan kenderaan → Extensions → Apps Script.
  2. Padam kod sedia ada dalam Code.gs, tampal kod di bawah, kemudian Save.
  3. Pilih fungsi setup → Run → benarkan akses (Authorize). Tab & header akan dibina jika tiada.
  4. Deploy → New deployment → Web app. Execute as: Me. Who has access: Anyone.
  5. Salin URL /exec, letak dalam MACRO_URL dalam fail HOD Site/Laporan Kenderaan/index.html, kemudian push ke GitHub.

Skrip guna active spreadsheet. Tab Laporan Kenderaan digunakan; jika tiada, tab pertama digunakan kalau header dia dah ada No Pendaftaran & Tarikh, kalau tidak tab baharu dibina. Bila ubah kod: Deploy → Manage deployments → Edit → New version supaya URL kekal sama. Salinan kod juga ada dalam fail Code.gs dalam folder ini.
